# 非公式TALTO移行ヘルパー

プレーンテキスト、各種Markdown、pixiv小説形式、HTML原稿を、TALTOの本文欄へ貼り付けやすい形へ変換するローカルツールです。TALTOへの貼り付けと保存確認は手作業で行います。

配布物は次の3つを同じソースから生成します。動作だけを隠した簡易版は生成しません。

- **ZIP版**（Windows向け、BOOTHで配布）: ソース・テスト・設計資料を同梱。展開して `非公式TALTO移行ヘルパー.html` を開く
- **Web版**（iPhone・iPad・Android向け、GitHub Pagesで配信）: 一度開いて「ホーム画面に追加」すると、以降はネット接続なしで起動できる
- **単一ファイル版**（ZIPに同梱）: CSS・JSを1つのHTMLに埋め込んだ予備版

いずれも原稿は端末内だけで処理し、外部へ送信しません。

## 使い方

1. `非公式TALTO移行ヘルパー.html` をブラウザで開く
2. 「変換を始める」を選ぶ
3. 「原稿」で「貼り付け」「ファイル」「フォルダ」から入力方法を選ぶ
4. 「形式」で実際の記述方法に合う原稿形式を選ぶ
5. 「設定」で空行や書式の変換方法を選ぶ
6. 「確認」で変換結果を確認し、リッチテキスト・書式なしテキスト・HTMLからコピー形式を選ぶ
7. TALTOの本文欄へ貼り付け、表示と保存完了を確認する

> **使用上の注意:** このツールは変換専用で、原稿を管理・編集するエディタではありません。元の原稿は必ず別に保管してください。重要な修正は元の原稿で行い、修正後にもう一度読み込んでください。

ブラウザの制限でローカルファイルからコピーできない場合は、このフォルダで `node tools/serve.mjs` を実行し、表示されたローカルURLを開いてください。詳しい変換仕様と安全な作業手順は [MIGRATION_GUIDE.md](docs/MIGRATION_GUIDE.md) に記載しています。

## 開発・改修

この版は、配布時のダブルクリック起動を保ったまま、役割別のフォルダへ分割しています。構成と変更箇所の案内は [ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。

Windows優先の品質を維持しながら、最新OSのiPad・iPhone・Androidへ段階的に対応し、BOOTHで無料配布するまでの計画は [CROSS_PLATFORM_BOOTH_RELEASE_PLAN.md](docs/CROSS_PLATFORM_BOOTH_RELEASE_PLAN.md) を参照してください。計画書には未実装項目を含みます。

開発用コマンドには Node.js 22 以降が必要です（ツール本体の利用だけなら Node.js は不要です）。

- 通常テスト: `node tests/test-converter.cjs`
- 構造テスト: `node tests/test-structure.cjs`
- ランダム入力テスト: `node tests/fuzz-converter.cjs`
- 画面幅・操作テスト（Playwright）: `npx playwright test`（初回は `npm install` と `npx playwright install chromium webkit`）
- ローカル表示: `node tools/serve.mjs`
- Web版の表示: `node tools/serve.mjs 8767 dist`（先に配布物作成が必要）
- 配布物作成: `node tools/build-release.mjs`（`--web-only` で `dist/` だけ）

配布物作成は、上記3種のテストを実行してから `VERSION.txt` の値で `../release/非公式TALTO移行ヘルパー_v<版>/` とその zip、および Web版の `dist/` を作ります。テストが1つでも失敗した場合は配布物を作りません。`main` へ push すると GitHub Actions が同じコマンドで `dist/` を作り、GitHub Pages へ配信します。

原稿はブラウザ上で処理されます。このツールはTALTOの非公開APIへ原稿を送信したり、TALTO上のデータを直接変更したりしません。

貼り付け原稿と読み込んだファイルは別々に保持され、入力方法で選んだ片方だけが変換されます。対応拡張子は `.md`、`.markdown`、`.html`、`.htm`、`.txt` です。ファイルは複数回に分けて追加しても既存の一覧へ保持されます。複数ファイルは一覧の上から下へ結合され、ドラッグ＆ドロップまたは上下ボタンで順序を変更できます。各行の×ボタンで一覧から外せますが、元ファイル自体は変更しません。

ファイルの中身は拡張子から自動判定せず、結合した原稿全体を「原稿の記述形式」で選んだ1種類として読み取ります。選択できるのは、プレーンテキスト、CommonMark、GFM、Obsidian Markdown、pixiv小説形式、HTMLです。HTML拡張子とそれ以外が混在する場合は、取り違え防止のため変換を停止します。内容と選択形式を確認した場合だけ強制実行できます。

フォルダ読み込みでは、フォルダ内の対応拡張子だけを相対パス順で一覧へ追加します。画像ファイル自体は読み込みません。対応記法の画像参照は「【画像：説明｜参照先】」という文字列で残し、その位置へTALTOで画像を手動挿入してください。

通常の容量上限は、ファイル読み込みが1ファイル10MB、フォルダ読み込みが対象原稿の合計100MBです。上限を超えた場合は読み込みを停止します。どうしても必要な場合は「変換オプション」の「ファイル容量の制限を解除」をONにしてから再度選択できますが、画面が固まる可能性があるため注意してください。

見出し1〜3が連続する箇所には専用の空行数を指定できます。この値は通常の「前／後」の空行より優先され、加算されません。設定値だけを端末内に保存し、原稿本文や読み込んだファイルは保存しません。

対応識別子のテスト原稿では、見出し1〜3・注釈・本文の全20表示に加え、選択した原稿形式で変換に対応している識別子をまとめて確認できます。Obsidian MarkdownとHTMLの対応表には、公式上の意味とTALTOでの表示、参照した公式案内を掲載しています。斜体と打消しはTALTO向けの出力では通常文字に簡略化します。書式の識別子は「挟む」「前後を別指定」「行頭のみ」「行末のみ」から選べます。

設定はデフォルトへ戻せるほか、原稿本文を含まないテキスト設定ファイルとして保存・読込できます。読み込んだ設定は種類別のカスタム設定として適用されます。
