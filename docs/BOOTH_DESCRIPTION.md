## 商品説明

### TaltoConv とは

手元の原稿（テキスト・Markdown・pixiv小説形式・HTML）を、TALTO の本文欄にそのまま貼り付けられる形に変換する道具です。見出し・注釈・太字・下線・空行を TALTO の書式に整えます。

TALTO の運営とは関係のない、個人制作の非公式ツールです。

### できること・できないこと

- 変換した本文をコピーして、TALTO の本文欄に貼り付けるところまでを助けます
- TALTO への貼り付け、画像の挿入、保存の確認は、ご自身の手で行います
- 画像ファイルは読み込みません。原稿内の画像の位置に「【画像：説明｜参照先】」という目印を残すので、それを見ながら TALTO 側で画像を挿入してください
- TALTO のアカウントやデータには一切アクセスしません

### 原稿の安全について

- 変換はお使いの端末の中だけで行います。原稿本文や読み込んだファイルを外部に送信することはありません
- ネット接続がなくても動きます（Windows版は最初から。スマホ版は一度開いてホーム画面に追加した後）
- 原稿本文を端末に保存することもありません。保存するのは変換の設定だけです

### 使い方（Windows）

1. このページからダウンロードした ZIP を展開します
2. 中にある **TaltoConv.html** を Microsoft Edge か Google Chrome で開きます（ダブルクリック）
3. 「変換を始める」→ 原稿を貼り付けるかファイルを選び、形式と設定を選んで「リッチテキストをコピー」
4. TALTO の本文欄に Ctrl+V で貼り付け、保存されたことを確認します

触るのは TaltoConv.html だけです。「TaltoConv_files」フォルダは動作に必要なファイルなので、移動・削除しないでください。
詳しい手順は同梱の「はじめにお読みください.txt」と、画面右上の「使い方」ボタンにあります。

### 使い方（iPhone・iPad・Android）

ZIP は使いません。Safari または Chrome で次の URL を開いてください。

**https://chicken1q84.github.io/TaltoConv/**

- iPhone・iPad: Safari の共有ボタン → 「ホーム画面に追加」
- Android: Chrome のメニュー（⋮）→ 「ホーム画面に追加」

一度追加すると、以降はホーム画面の「TaltoConv」から起動でき、ネット接続がなくても使えます。コピーがうまくいかない場合は画面の「手動でコピーする」欄から、すべて選択 → コピーで写せます。

### 対応環境

| 端末 | 対応 |
|---|---|
| Windows 11 | 最新の Microsoft Edge または Google Chrome |
| iPhone・iPad | 最新の iOS / iPadOS と Safari |
| Android | 最新の Android と Google Chrome |

古い OS、アプリ内ブラウザ（X・LINE など）、上記以外のブラウザは動作保証の対象外です。
iPad と Android は制作者の手元に実機がなく、画面のエミュレーションで確認しています。不具合があれば教えてください。

### 対応する原稿

プレーンテキスト、CommonMark、GFM、Obsidian Markdown、pixiv小説形式、HTML。
ファイルは .txt / .md / .markdown / .html / .htm を読み込めます。
