TaltoConv（非公式TALTO移行ヘルパー）
====================================

手元の原稿（テキスト・Markdown・pixiv小説形式・HTML）を、TALTO の本文欄に
そのまま貼り付けられる形に変換する道具です。

TALTO の運営とは関係のない、個人が制作した非公式ツールです。
バージョンは画面の一番下に表示されます。


■ 1. 始め方（Windows）

  1. このフォルダにある「TaltoConv.html」をダブルクリックします
     （Microsoft Edge または Google Chrome で開いてください）
  2. 「変換を始める」を押します

  触るのは「TaltoConv.html」だけです。
  「TaltoConv_files」フォルダには動作に必要なファイルが入っています。
  中身を移動・削除・改名せず、TaltoConv.html と同じ場所に置いたまま使ってください。

  ネット接続は不要です。原稿が外部に送られることもありません。


■ 2. iPhone・iPad・Android で使う

  この ZIP は使いません。Safari または Chrome で次の URL を開いてください。

    https://chicken1q84.github.io/TaltoConv/

  iPhone・iPad … Safari の共有ボタン（□に↑）→「ホーム画面に追加」
  Android    … Chrome のメニュー（⋮）→「ホーム画面に追加」

  一度追加すると、以降はホーム画面の「TaltoConv」から起動でき、
  ネット接続がなくても使えます。


■ 3. 使い方の流れ

  01 原稿  … 貼り付けるか、ファイル・フォルダから読み込みます
  02 形式  … 原稿の書き方（Markdown の種類など）を 1 つ選びます
  03 設定  … 空行や太字・下線などの変換方法を決めます
  04 確認  … 結果を見て「リッチテキストをコピー」を押します

  そのあと TALTO の本文欄に貼り付けます（Windows は Ctrl+V、スマホは長押し→ペースト）。
  貼り付けたら、保存済みの表示を待ってから一度再読み込みし、
  見出しや太字が残っているか確認してください。

  画面右上の「使い方」ボタンからも、この流れをいつでも確認できます。


■ 4. 困ったとき

  コピーボタンを押しても TALTO に貼れない
    → 画面の「自動コピーがうまくいかない場合」を押すと、手動でコピーする欄が開きます。
      欄の「すべて選択」→ コピー の順で写してください。

  TaltoConv.html を開いても画面が真っ白／崩れている
    → 「TaltoConv_files」フォルダが同じ場所にあるか確認してください。
      それでも直らない場合は、TaltoConv_files の中の
      「TaltoConv_単一ファイル版.html」を開いてみてください（動作は同じです）。

  画像が入らない
    → 画像ファイルは読み込みません。原稿内の画像の位置に「【画像：説明｜参照先】」という
      目印が残るので、それを見ながら TALTO 側で画像を挿入し、目印を消してください。

  大きな原稿で画面が固まる
    → 原稿を冊子ごとに分けて、少しずつ変換してください。


■ 5. 必ず守ってほしいこと

  ・元の原稿は必ず別に保管してください。このツールは変換専用で、原稿を編集・管理しません。
  ・最初は短い原稿で試し、TALTO に貼り付けた後の表示と保存を確認してから本番の原稿を移してください。
  ・変換する原稿は、ご自身が使用・移行する権利をお持ちのものに限ってください。
  ・TALTO 側の仕様変更により、変換結果が変わる可能性があります。

  本ツールの利用によって生じたデータの消失、表示崩れ、保存失敗、その他の損害について、
  制作者は責任を負いません。


■ 6. 対応環境

  Windows 11    … 最新の Microsoft Edge または Google Chrome
  iPhone・iPad  … 最新の iOS / iPadOS の Safari（Web 版）
  Android       … 最新の Android の Google Chrome（Web 版）

  古い OS、アプリ内ブラウザ（X・LINE など）、上記以外のブラウザは動作保証の対象外です。
  詳しくは TaltoConv_files/docs/対応環境.md と 既知の問題.md をご覧ください。


■ 7. 対応する原稿

  貼り付け        … プレーンテキスト、CommonMark、GFM、Obsidian Markdown、pixiv小説形式、HTML
  ファイル・フォルダ … .txt / .md / .markdown / .html / .htm

  複数のファイルは一覧の上から順に 1 つの原稿として結合されます。
  ファイルの種類は自動判定しないので、「02 形式」で書き方を選んでください。


■ 8. 改修したい方へ

  TaltoConv_files の中に、ソース（src/）、テスト（tests/）、設計資料（docs/）、
  変更履歴（CHANGELOG.txt）が入っています。構成と変更箇所の案内は
  docs/ARCHITECTURE.md を、変換の仕様は docs/MIGRATION_GUIDE.md をご覧ください。
