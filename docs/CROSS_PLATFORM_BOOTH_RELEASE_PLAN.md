# クロスプラットフォーム対応・BOOTH無料配布計画（改訂版）

更新日: 2026-09-17（初版 2026-09-16 を改訂。変更理由は [PLAN_REVIEW_2026-09-16.md](PLAN_REVIEW_2026-09-16.md)）

## 位置づけ

TaltoConv（非公式TALTO移行ヘルパー）をWindows優先で維持しながら、最新OSのiPad・iPhone・Androidへ段階的に対応し、最終的にBOOTHで無料配布するための計画です。

これは計画であり、書かれた項目がすべて実装済みという意味ではありません。完了した項目は各Phaseのチェックボックスと `CHANGELOG.txt` へ反映します。

## 確定事項

| 事項 | 決定 |
|---|---|
| 目標 | Windows・iOS・Androidすべてで**完全オフライン動作**（ネット接続なしで起動・変換・コピーができる） |
| Windowsの経路 | BOOTHのZIPを展開してHTMLを直接開く（現行どおり） |
| iOS・Androidの経路 | **PWA**を主経路。初回だけHTTPSで開き「ホーム画面に追加」すると、以降はオフラインで起動する |
| 予備経路 | CSS・JSをすべて埋め込んだ**単一ファイルHTML**をZIPへ同梱。Androidの一部環境で直接開ける。iOSでは動作保証しない |
| ホスティング | **GitHub Pages**（無料・カード不要・広告や解析の差し込みなし・サーバー保守なし） |
| ライセンス | **MIT**（ZIP同梱分・Web公開分とも同じ） |
| アプリ名 | **TaltoConv**（正式名称は「非公式TALTO移行ヘルパー」。ホーム画面・ZIP名・画面表示は TaltoConv） |
| 自動テスト | Node単体の `tests/`（ZIPに同梱）と、Playwrightの `e2e/`（開発専用、ZIPに含めない） |
| リポジトリ | `migration-helper-v2/` をルートにする。作業フォルダ直下のTALTO復元コードと通信記録は含めない |

## 最終目標

- Windowsを最優先の基準環境とし、既存機能を後退させない。
- iPad・iPhone・Androidは、リリース時点の最新正式版OSと標準ブラウザに最適化する。
- **原稿の変換は端末内だけで行い、原稿本文や読み込んだファイルを外部へ送信しない**（実装済み。以後も維持する）。
- **ネット接続なしで起動できる**（Windowsは実装済み。モバイルはPWAで実現する）。
- BOOTHではWindows用ZIPを0円で配布し、商品説明と同梱説明書からPWA版へ案内する。
- TALTOへの貼り付け、画像挿入、保存確認は利用者が手作業で行う。

「送信しない」と「ネットなしで動く」は別の要件です。前者は原稿の扱い、後者は起動経路の話として区別して説明します。

## 正式サポート方針

| 対象 | 正式対応範囲 | 経路 |
|---|---|---|
| Windows | Windows 11、最新のMicrosoft EdgeまたはGoogle Chrome | ZIP → HTML直開き |
| iPhone | 配布時点の最新正式版iOSを導入できる機種、Safari | PWA（ホーム画面に追加） |
| iPad | 配布時点の最新正式版iPadOSを導入できる機種、Safari | PWA（ホーム画面に追加） |
| Androidスマートフォン・タブレット | 配布時点の最新正式版Android、最新のGoogle Chrome | PWA。単一ファイルHTMLは参考対応 |
| その他のデスクトップブラウザ | 参考対応。正式な動作保証は個別に判断する | |
| アプリ内ブラウザ | 動作保証外。SafariまたはChromeで開くよう案内する | |
| 古いOS・更新対象外端末 | UI最適化と不具合対応の対象外 | |

画面最適化は機種名だけで判断せず、コンパクト／標準／大型スマートフォン、小型／大型タブレット、タブレットの分割表示、縦向きと横向きで確認します。

## 配布構成

```text
同じソース
  ├─ tools/build-release.mjs ─┬─ release/<名前>_v<版>/ とzip   … BOOTHへ
  │                            │    ├─ TaltoConv.html            … 利用者がクリックする唯一のファイル
  │                            │    ├─ はじめにお読みください.txt
  │                            │    └─ TaltoConv_files/          … 触らなくてよいもの
  │                            │         ├─ TaltoConv_単一ファイル版.html（予備）
  │                            │         └─ src/ tests/ docs/ tools/serve.mjs CHANGELOG LICENSE VERSION
  │                            └─ dist/                          … GitHub Pagesへ
  │                                 ├─ index.html
  │                                 ├─ manifest.webmanifest
  │                                 ├─ sw.js
  │                                 └─ src/ icons/
  └─ VERSION.txt … 画面表示・manifest・SWキャッシュ名・zip名の唯一の情報源
```

- ZIPとWeb版は同じコマンドで同時に生成し、片方だけ更新できないようにします。
- GitHub Pagesには静的なHTML・CSS・JSだけを置き、原稿を受け取るAPIは設置しません。
- GitHub Pagesはスクリプトを差し込まないため、Web版でも通信は自分のファイルの取得だけです。Phase 1で実測して確認します。

### PWAのオフライン方針

- Service Workerは配信ファイル一式を初回に全部キャッシュする（precache）。
- キャッシュ名に `VERSION.txt` の値と配信ファイル全体のハッシュ（BUILD_ID）を含め、新しい版のSWが有効化された時点で旧キャッシュを削除する。バージョンを上げずにファイルだけ差し替えた場合も、ハッシュが変わることで利用者側の更新が走る。
- 新しい版を検出したら画面に「新しい版があります。再読み込みしてください」を表示する。
- iOS Safariはホーム画面に追加していないサイトの保存データを一定期間の未使用後に消すことがあるため、オフライン利用の案内では「ホーム画面に追加」を必須手順にする。

不具合区分:

- Blocker: 起動不能、コピー不能、移行不能、データ消失につながる挙動。公開不可。
- Major: 主要操作が画面外、代替手段がない機能停止、変換結果の重大な誤り。公開不可。
- Minor: 文言、余白、限定的な見た目。回避策を記載できる場合は公開判断可能。

完了条件: BlockerとMajorが0件。Minorは影響範囲と回避策を `docs/既知の問題.md` に記載している。

### Phase 9: BOOTH正式配布

### Phase 10: 公開後の保守

サーバーが存在しないため、OS更新・バックアップ・障害対応は発生しません。やることはZIP版と同じで「直したら置き直す」だけです。

- `VERSION.txt` を上げ、`tools/build-release.mjs` でZIPと `dist/` を同時に作り、BOOTHのファイル差し替えと `main` へのpushを行う。
- `CHANGELOG.txt` へ修正内容と影響環境を記載する。
- TALTO側の仕様変更が疑われる場合、共通テスト原稿で再検証する。
- モバイルOSのメジャー更新後はコピー、ファイル選択、TALTO貼り付け、オフライン起動を優先して再確認する。
- 不具合報告へ原稿本文の添付を求めず、再現用の最小サンプルを依頼する。

## 全端末共通の人力テスト

### 変換

- プレーンテキスト、CommonMark、GFM、Obsidian Markdown、pixiv小説形式、HTML。
- 見出し1～3、注釈、本文、太字、下線。
- Setext見出し、行全体の斜体、区切り線。
- リスト、タスク、表、リンク、画像参照。
- 危険なHTMLが実行されず文字化または除外されること。

### 空行と設定

- 一括設定と種類別設定。
- 先頭と末尾の空行。
- 連続見出し専用の空行。
- 0行と10行。
- カスタム識別子の4方式。
- 設定初期化、設定ファイル保存と読込、旧版設定との互換性。

### TALTO連携

- 空の冊子への貼り付け。
- 既存本文を置換する場合の選択範囲確認。
- 貼り付け直後、保存済み表示、再読み込み後の表示。
- 画像プレースホルダーを目印にした画像挿入と、その後のプレースホルダー削除。

### 安全性・オフライン

- 元ファイルが変更されないこと。
- 一覧から外しても元ファイルが削除されないこと。
- 原稿本文がlocalStorageへ保存されないこと。
- コピーや読込失敗時にも原稿欄が消えないこと。
- Web版で原稿本文を送信する通信がないこと。
- 機内モードで起動・変換・コピーができること。

## v1.0.0公開判定

次をすべて満たした場合だけ正式版とします。

1. Windows版の既存機能を後退させていない。
2. Windows、iPhone、iPad、AndroidでリッチテキストをTALTOへ貼り付け、保存後の再読み込みまで確認できた。
3. iPhone、iPad、Androidでホーム画面に追加し、機内モードで起動・変換・コピーができた。
4. 自動コピー失敗時に手動コピーへ到達できる。
5. フォルダ非対応環境でも、貼り付けまたは複数ファイル選択で完了できる。
6. 横崩れ、長時間の無反応、原稿消失につながるBlockerとMajorが0件である。
7. BOOTHから入手したZIPを新しいフォルダへ展開し、同梱説明書だけでWindows版を開始できる。
8. BOOTHの商品説明だけで、モバイル利用者がPWA版へ到達し、ホーム画面に追加できる。
9. 画面、ZIP名、README、VERSION、CHANGELOG、Web版のバージョンが一致する。
10. 非公式ツール、免責、MITライセンス、対応環境、画像の手動挿入、元原稿保管の注意を明記している。
