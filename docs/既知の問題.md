# 既知の問題と制限

更新日: 2026-09-17（v1.0.0 準備中）

「制限」は仕様として割り切っているもの、「問題」は直したいが未対応のものです。回避策があるものは併記します。

## 制限（仕様）

| 内容 | 理由 | 回避策 |
|---|---|---|
| 画像ファイルを読み込まない | TALTO の画像は TALTO 側でしか登録できないため | 原稿内の画像の位置に残る「【画像：説明｜参照先】」を目印に、TALTO で画像を挿入し、目印を消す |
| リスト・表・リンクは通常の段落になる | TALTO の本文に専用の書式がないため | 記号（・、1.、｜）と URL を文字として残すので、読みやすさは保たれる |
| 斜体・打消し線は通常文字になる | TALTO の本文で使えないため | 行全体が斜体の箇所は設定で「注釈」に変えられる |
| 見出し 4〜6 は太字の段落になる | TALTO の見出しは 1〜3 のみ | — |
| iPhone・iPad でフォルダを選べない | iOS のファイル選択にフォルダを選ぶ機能がないため | 「ファイル」から複数のファイルをまとめて選ぶ |
| Web 版は初回だけネット接続が必要 | 一度開いて端末に保存する仕組みのため | ホーム画面に追加した後は不要 |
| ZIP 版に更新の通知は届かない | ZIP は端末内で完結し、外部と通信しないため | BOOTH の更新情報を確認する。Web 版は自動で案内が出る |
| ファイルの種類を自動判定しない | Markdown の方言や pixiv 形式は拡張子から判別できないため | 「02 形式」で原稿の書き方を選ぶ |

## 問題（未対応）

現時点で報告されている問題はありません。

見つかった場合はここに「現象・影響する環境・回避策・対応予定」を追記します。
