# 対応環境

更新日: 2026-09-18（v1.0.0）

バージョンは 2026 年 9 月 17 日時点の最新正式版です。OS・ブラウザの更新に合わせて見直します。

## 正式に対応する環境

| 端末 | OS | ブラウザ | 使い方 |
|---|---|---|---|
| Windows パソコン | Windows 11 25H2 | Microsoft Edge 153 / Google Chrome 153 以降（自動更新で最新になっていれば可） | ZIP を展開して `TaltoConv.html` を開く。Web 版でも可 |
| iPhone | iOS 27 | Safari | Web 版をホーム画面に追加 |
| iPad | iPadOS 27 | Safari | Web 版をホーム画面に追加 |
| Android スマートフォン・タブレット | Android 17 | Google Chrome 153 以降 | Web 版をホーム画面に追加。**実機では未検証** |

1 つ前の版（Windows 11 24H2、iOS / iPadOS 26、Android 16 など）でもたいてい動きますが、不具合対応の対象は上記の版だけです。Edge と Chrome は 2 週間ごとに更新されるため、番号は目安です。

Android は制作者の手元に実機がなく、**未検証**です（画面のエミュレーションのみ確認）。動作報告をいただけると助かります。

## 参考対応（動くことが多いが保証しない）

- Windows 10、macOS の Edge・Chrome・Safari・Firefox
- iOS / iPadOS の Chrome（中身は Safari と同じ仕組みなので、ほぼ同じ挙動になります）
- Android の Firefox・Samsung Internet

## 動作保証の対象外

- アプリ内ブラウザ（X、LINE、Discord などの中で開いたページ）。Safari または Chrome で開き直してください
- 古い OS・更新が終了した端末
- Internet Explorer

## 機能ごとの違い

| 機能 | Windows | iPhone・iPad | Android |
|---|---|---|---|
| 貼り付けで原稿を入れる | ○ | ○ | ○ |
| ファイルを選んで読み込む（複数可） | ○ | ○ | ○ |
| フォルダをまとめて読み込む | ○ | × （ファイルから複数選択してください） | 端末による |
| リッチテキストの自動コピー | ○ | ○（許可されない場合は手動コピー） | ○（同左） |
| 手動コピー（すべて選択 → コピー） | ○ | ○ | ○ |
| ネット接続なしで起動 | ○（最初から） | ○（ホーム画面に追加した後） | ○（同左） |
| 画面の並び | 原稿・設定と結果を横並び | 縦向きは工程ごと、iPad 横向きは横並び | 幅による |

## 容量の目安

| 端末 | 1 ファイル | 合計 |
|---|---:|---:|
| Windows | 10MB まで | フォルダ 100MB まで |
| スマートフォン | 5MB を超えると確認 | 20MB を超えると確認 |
| タブレット | 10MB を超えると確認 | 30MB を超えると確認 |

Windows の上限は設定の「ファイル容量の制限を解除」で外せますが、画面が固まる可能性があります。スマートフォン・タブレットでは上限内でも確認を求め、読み込むかどうかを選べます。

## 実機での確認状況

| 環境 | 状況 |
|---|---|
| Windows 11 + Edge / Chrome | 制作者の実機で確認 |
| iPhone + Safari | 制作者の実機で確認（ホーム画面追加、機内モード起動、コピー、TALTO 貼り付け） |
| iPad + Safari | エミュレーションのみ（縦向き・横向き） |
| Android + Chrome | **未検証**（エミュレーションのみ。実機での動作報告を募集中） |

実機で未確認の環境で問題があった場合は、[既知の問題](既知の問題.md) に追記します。
