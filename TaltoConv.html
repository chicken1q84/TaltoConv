非公式TALTO移行ヘルパー

原稿を、TALTO用に整える。

テキスト・Markdown・pixiv小説形式・HTMLを、見出しや太字を保ったままコピーできます。原稿は外部へ送信しません。

この端末で始める

WindowsパソコンMicrosoft Edge または Google Chrome＋
  1. ZIPを展開し、TaltoConv.html をダブルクリックします。
  2. 変換結果をコピーし、TALTOへ Ctrl+V で貼り付けます。
iPhoneSafari＋
  1. Safariで Web版を開く（アプリ内ブラウザは使いません）。
  2. 共有ボタン（□に↑）→「ホーム画面に追加」。追加後はオフラインでも使えます。
  3. コピー後、TALTOの本文欄を長押しして「ペースト」します。
iPadSafari＋
  1. Safariで Web版を開きます。
  2. 共有ボタン（□に↑）→「ホーム画面に追加」。追加後はオフラインでも使えます。
  3. コピー後、TALTOの本文欄を長押しして「ペースト」します。
Androidスマートフォン・タブレットGoogle Chrome＋
  1. Chromeで Web版を開きます。
  2. メニュー（⋮）→「ホーム画面に追加」。追加後はオフラインでも使えます。
  3. コピー後、TALTOの本文欄を長押しして「貼り付け」ます。

  • 対応拡張子：.md / .markdown / .html / .htm / .txt
  • 対応する記述形式：プレーンテキスト、CommonMark、GFM、Obsidian Markdown、pixiv小説形式、HTML
  • 一覧の上から下へ結合し、全体を「02 形式」で選んだ1種類として読み取ります
  • HTML拡張子とそれ以外が混在する場合は、確認のため自動変換を停止します

    変換メモ

      コピーした内容をTALTOの本文欄へ貼り付けてください。

      手動でコピーする

      下の欄を長押し（PCでは欄内をクリック）→すべて選択→コピーの順に操作してください。「すべて選択」ボタンを押すと選択までを代わりに行います。

      使い方

      1. 原稿を貼り付けるか、ファイルを選びます。
      2. 形式を選び、必要なら空行や書式を設定します。
      3. 確認で「リッチテキストをコピー」を押します。
      4. TALTOの本文欄へ Ctrl+V（Macは ⌘+V）。保存後に見出しや太字を確認します。

      コピーできない場合は「自動コピーがうまくいかない場合」を押してください。画像は「【画像：…】」を目印にTALTOで挿入します。

      1. 原稿を貼り付けるか、「ファイル」から選びます。
      2. 画面下のボタンで形式 → 設定 → 確認へ進みます。
      3. 「リッチテキストをコピー」を押します。失敗したら「すべて選択」→「コピー」。
      4. TALTOの本文欄を長押しして「ペースト」（Androidは「貼り付け」）。保存後に書式を確認します。
